## 最容易记错的几句话

- 极限看函数值趋向哪里；导数看差商趋向哪里。
- 可导一定连续；连续不一定可导。
- 左右极限相等，只解决双侧极限是否存在；还不能保证连续或可导。
- 端点按定义域和课件的单侧导数约定处理。
- 分母为零只给竖直渐近线的候选位置，约分后可能只是一个空点。
- 复合求导要保留内层，再乘内层导数；求时间变化率要看清 $dx/dt$。
- 线性近似用中心处的 $f'(a)$；$dy$ 估计变化量，新值还要加回 $f(a)$。
- 临界点只是极值的候选位置；闭区间求绝对极值还要比较端点。
- 等价替换遇到相减先检查主项是否抵消；洛必达每用一次都检查条件。

## Week 5 易错提醒

- $f'>0$ 看上升，$f''>0$ 看斜率增加；二者不同。
- $f''=0$ 不保证拐点；拐点也不要求二阶导数存在。
- 二阶极值检验先要求驻点；检验失败不等于没有极值。
- 最优化先定可行域；内部驻点不自动是全局最优。
- 牛顿法求零点，可能循环、发散或收敛到其他根。

## Week 6 易错提醒

- 原函数靠求导验证；一般不定积分要保留任意常数。
- 除以常数内层系数，不等于能除以任意内层导数。
- 等分区间的总长度 = 段数 × Δx；和式前的系数还可能含函数常数。
- 左和与上和不是同一概念，单调性决定左右估计方向。
- 不等分黎曼和要看最长小段趋于零，不能只看段数增加。
- 累积速度得到位移，累积速率得到路程。
